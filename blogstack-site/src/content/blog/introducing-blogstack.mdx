BlogStack combines native React blog components with a hosted publishing dashboard. Developers keep the website routes and styles; clients manage articles through a project-scoped workspace.

The launch includes private drafts, explicit publication, SEO checks, link health, optional reader analytics and reviewable AI suggestions. Start with the Next.js reference integration for server-rendered article content, metadata, RSS and a separate blog sitemap.

Plans start at $3/month. Studio and Growth support unlimited blogs with shared account allowances. Every new publishing account begins with a no-card, 14-day Studio trial.

This announcement remains a draft until production verification and the paying pilot are complete.
