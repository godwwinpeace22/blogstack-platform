# BlogStack platform

A hosted publishing workspace with native website components, a public JavaScript SDK, SEO checks, link health, optional reader analytics and human-reviewed AI proposals.

The root npm workspace builds the existing API, dashboard, public packages, registry, marketing site and documentation together. The Next.js reference is in examples/nextjs. Original repository folders remain intact.

Start with Node 24, Bun 1.4.0, npm ci, npm run build:packages, npm run setup:local and npm run migrate:local. Run dev:api, dev:cdn and dev:dashboard in separate terminals.

See docs/LAUNCH.md for production resources, the six Polar prices, pilot controls, checks and remaining external launch gates. See docs/RESTORE.md for the backup and restoration procedure. Checkout is disabled and production signup is pilot-only by default.

See docs/VERIFICATION.md for completed checks, browser evidence and the production gates still open.

Canonical plans are Solo $3/$30, Studio $9/$90 and Growth $19/$190 for monthly/annual billing. Studio and Growth have unlimited blogs; Growth includes 100 GB shared storage. All plans include the public API, SEO analysis, analytics and reviewable AI within their account allowances.
