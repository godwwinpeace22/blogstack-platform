---
title: Customization
description: Keep your native routes and editable MIT components.
---

Components inherit theme tokens and accept className. Import @blogstack/ui/theme for a starting theme or supply your website's existing variables. Include package source paths in Tailwind CSS 4 scanning.

The registry installs source files into your project. You can edit markup and styles and keep the MIT license. Paid attribution removal is a convenience setting and agency workspace feature; it does not restrict editing downloaded MIT source.

For an indexed website, fetch articles on the server, pass initialPost and render publicationMetadata and articleJsonLd. Keep the host's route structure, sitemap and robots rules.

Use commentsSlot and newsletterSlot for provider components/forms. renderContent can replace article rendering, but you then own sanitization and server output. Custom dataSource implementations must return the documented public post/list shapes.
