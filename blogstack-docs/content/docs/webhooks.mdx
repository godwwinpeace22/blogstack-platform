---
title: Release scope
description: Features deliberately deferred from the paid launch.
---

Customer webhooks, scheduled publishing, native embedded admin, live collaboration, suggestion mode, multilingual publishing, ownership transfer, MCP and additional framework adapters are not enabled in this release.

Legacy webhook/scheduling/collaboration routes return a feature-unavailable response. Existing legacy plan labels never confer paid launch access.

The Polar billing webhook is an internal payment integration. It is signed, deduplicated and reconciled against authoritative provider state. It is not a customer-configurable content webhook.
