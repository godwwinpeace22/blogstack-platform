# Security reports

Please report vulnerabilities privately to hello@boldlaunchstudio.com with the subject **BlogStack security report**. Include the affected source revision, reproduction steps using a disposable environment and the potential impact. Do not include live credentials, private customer content or identity documents.

Do not disclose an unpatched vulnerability in a public issue or test against accounts and infrastructure you do not control. We will acknowledge reports as capacity allows; there is no promised response SLA or paid bounty.

Self-hosting operators manage their own infrastructure, secrets, updates, provider budgets, email, backup restoration and incident response. Deploy a reviewed revision, restrict operator access and keep external backup copies. Report problems in the application source so fixes can benefit both managed and self-hosted installations.
